# Hyrox & CrossFit Prep Planner

An AI-powered workout planner that generates personalized training programs for Hyrox and CrossFit preparation. The app creates a comprehensive 4-week plan tailored to your fitness level, focusing on strength, endurance, and functional fitness.

## 🌟 Features

- **Personalized Plans**: Choose from Beginner, Intermediate, or Advanced difficulty levels
- **Structured Training**: Weekly plans with Push, Pull, Legs, HIIT, and Endurance days
- **Progress Tracking**: Mark workouts as completed and track your journey
- **Mobile Friendly**: Fully responsive design for on-the-go access
- **Dark Mode**: Easy on the eyes during late-night planning

## 💻 Run Locally

**Prerequisites:** Node.js

1. Clone the repository:
   ```bash
   git clone https://github.com/ruangwithviwathanatepa/hyrox-crossfit-prep-planner.git
   cd hyrox-crossfit-prep-planner
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   - Create a `.env.local` file in the root directory
   - Add your Gemini API key:
     ```
     GEMINI_API_KEY=your_api_key_here
     ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) in your browser
